Minecraft assets (texturas, modelos y recetas)

GeyserMC mapeo de items Java ↔ Bedrock

El archivo geyser-item-map.json procede del repositorio GeyserMC/mappings y se usa para traducir IDs entre Java y Bedrock.

  • Repositorio: github.com/GeyserMC/mappings
  • Licencia: MIT (ver el archivo LICENSE del repositorio)

Cubiomes (motor de generación de biomas)

La herramienta Seed Map calcula biomas con la librería cubiomes (fork xpple/cubiomes de Cubitect/cubiomes), incluida como submodule y compilada a WebAssembly. Enlazada desde código propio GPL-3.0; su licencia MIT se conserva intacta.
