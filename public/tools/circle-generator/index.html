Información

Los comandos /fill y /setblock usan la misma sintaxis en Java y Bedrock: la salida funciona en ambas ediciones sin cambios.

El archivo .mcfunction sirve como función de un Data Pack en Java o de un Behavior Pack en Bedrock.

Con diámetros pares el centro cae entre dos bloques; con diámetros impares el bloque central coincide con la coordenada introducida.

La imagen .png descargada es un plano a escala con cuadrícula, útil como plantilla para construir el círculo a mano.
